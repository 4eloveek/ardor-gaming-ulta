# ultactl для Ardor Gaming Ulta

CLI и интерактивное меню для настройки мыши Ardor Gaming Ulta в Linux.
Один файл на Python 3 (только стандартная библиотека), ничего
устанавливать не нужно: RGB-подсветка, DPI, частота опроса, заряд
батареи, LOD, поведение подсветки при движении.

Поддерживаемые USB ID:

| Подключение | VID:PID |
|---|---|
| Донгл 2.4 ГГц | `25a7:fa7c` |
| Кабель | `25a7:fa7b` |

Автопоиск выбирает HID-интерфейс с feature report 0x08 (командный
интерфейс). Если одновременно воткнуты кабель и донгл, приоритет у
кабеля. Настройки хранятся в EEPROM мыши и переживают выключение.

## Запуск

    python3 ultactl.py status
    python3 ultactl.py battery

Без аргументов (`python3 ultactl.py`) открывается интерактивное меню
(режим, цвет, яркость, скорость, DPI, частота опроса, заряд,
подсветка при движении). Для постоянной команды:

    mkdir -p ~/.local/bin
    ln -sfull $(pwd)/ultactl.py ~/.local/bin/ultactl

## Команды

    ultactl status                 # подключение, заряд, подсветка, опрос, DPI
    ultactl battery                # заряд и зарядка
    ultactl steady red -b 80       # статичный цвет + яркость 0-100
    ultactl breath '#ff8800' -l 5  # дыхание, скорость уровнем 1-10 (1 медленно)
    ultactl stream -l 3            # «поток» (перелив всех цветов)
    ultactl neon -l 4              # «неон» (мигание)
    ultactl colorbreath -b 50      # радужное дыхание
    ultactl scroll orange          # «бег» цветом
    ultactl off                    # подсветка выключить
    ultactl dpi set 2 1600         # ступень 2 = 1600 DPI
    ultactl dpi active 2           # активная ступень DPI
    ultactl poll 500               # частота опроса: 125/250/500/1000 Гц
    ultactl motion off             # гасить подсветку при движении
    ultactl motion on              # подсветка горит при движении
    ultactl colors                 # список именованных цветов

Цвет задаётся именем (`red`, `orange`, …), шестью hex-цифрами
(`ff8800`) или тремя числами через запятую (`255,128,0`).
В статичном режиме и цветных эффектах используется выбранный цвет;
в `stream`, `neon`, `colorbreath` цвет прошивка игнорирует.

Диапазон DPI: 50–19000. До 10000 шаг 50, после — шаг 100. Смена
режима/цвета/яркости пишет запись подсветки в EEPROM целиком.
Все настройки сохраняются в памяти мыши: настройки переживают
переподключение и питание.

## Пробуждение мыши

Беспроводная мышь засыпает; утилита ждёт движения до 180 секунд и
подсказывает: «подвигайте ее или нажмите кнопку». При выдёргивании
кабеля или переключении транспорта в интерактивном меню подключение
поднимается заново автоматически (сообщение «переподключаюсь...»).

Если запуск пишет «мышь не найдена», проверьте, что донгл воткнут,
или подключите мышь кабелем.

## Доступ через udev

Если запуск сообщает об отсутствии прав на `/dev/hidrawN`:

    sudo install -Dm644 70-ardor-ulta.rules /etc/udev/rules.d/70-ardor-ulta.rules
    sudo udevadm control --reload-rules
    sudo udevadm trigger --subsystem-match=hidraw

После этого переподключите донгл или кабель и запускайте от своего
пользователя (root не нужен).

## Дамп EEPROM

    python3 ulta_dump.py

Дампер использует тот же протокол, ждёт пробуждения и читает образ
`0x0000–0x0100` с проверкой контрольных сумм ответов. Пути
`/dev/hidraw5` (командный интерфейс) и `/dev/hidraw4` (наблюдение
пробуждения) заданы константами `CFG` и `MSE` в начале файла — при
другой нумерации поправьте их под себя или воспользуйтесь
`ultactl status`, чтобы узнать актуальный узел.

## Тесты

    python3 -B -m unittest discover -s tests

Тесты проверяют чистую логику без железа: формулы контрольных сумм
против живых пакетов режима 25a7:fa7c, компоновку пакетов чтения и
записи EEPROM, кодирование/декодирование DPI, разбор цветов,
таблицы скорости/яркости, детекцию командного интерфейса и
обработку «подсветки при движении».

## Источники и лицензия

Протокол чипа Compx/JM03, карта EEPROM, таблицы RGB и кодирование DPI
сверены с [VitaminDB/ardor-mouse](https://github.com/VitaminDB/ardor-mouse)
(реверс официальной утилиты Ardor Edge Air Ultra, тот же чип) и
подтверждены на живой Ulta: дампы EEPROM, ответ «заряд», запись
подсветки и DPI. Уровни скорости/яркости и режимы «потока» взяты из
таблиц firmware, анализированных в указанном проекте.
